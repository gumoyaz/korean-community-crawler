## 2026-04-24 ~ 04-30 — 첫 구축 (Flask + Railway)

- Flask 앱과 gunicorn으로 시작해 Railway에 배포했다. 사이트 이름은 "커트"로 정했다.

  - 4/29부터는 API를 주 경로로 쓰고, 직접 스크래핑은 예비 경로로 돌렸다.
- `/daily` 데일리 리포트(Gemini 요약)를 만들었다.
  - 처음엔 KST 자정에 만들다가 낮 12시 생성으로 바꿨다.
  - 읽어주기(TTS) 플레이어와 섹션 이동을 넣었다.
- 게시글 velocity 추적과 급상승 키워드, 단어 구름 불용어(STOP_WORDS) 1차 정리를 했다.

## 2026-09-23 ~ 09-24 — 전면 점검과 GitHub Pages 이전

### 점검
에이전트 여러 개로 코드를 점검했다. 발견 78건 중 확인 51건, 심각도 조정 26건, 기각 1건이었다. 크게 영향을 준 것은 이렇다.
- todaybeststory를 1,300건 가운데 앞 300건만 받고 있었다. 조회수 순이라 클리앙·오유·SLR·개드립 등 8곳이 통째로 빠졌다.
- 요약 칸에 게시판 이름(postDesc)이 들어갔고, FM코리아 조회수는 API의 합성값이라 데일리 선정을 FMK가 과점했다.
- 시간대 버그로 카드 시각이 09:00으로 고정되거나 9시간 밀렸다.
- 재시작 직후 모든 키워드가 급상승으로 떴다. 크롤이 실패하면 피드가 빈 목록으로 덮였다.
- 재생성·새로고침·디버그 API에 인증이 없어서 누구나 리포트를 덮어쓸 수 있었다.
- 직접 스크래핑은 대부분 고장이었다: MLB파크 URL, 아카라이브 구조 변경, 인스티즈·FM코리아 차단, 행 어긋남.
- Gemini 키가 무효였고, `gemini-2.5-flash`는 "과거 사용자 전용"으로 제한됐다.

### 호스팅 결정
무료 호스팅을 조사하고 공식 문서로 교차 확인했다.
- **GitHub Actions + GitHub Pages**를 골랐다. 월 0원이고 카드가 필요 없다. 데일리 리포트를 리포에 커밋하면 영구 보존된다.
- 다른 후보가 탈락한 이유:
  - Render: 15분 요청이 없으면 꺼지고 디스크가 휘발성이다.
  - Koyeb: 신규 무료 가입이 막혔다.
  - Cloudtype: 무료 플랜은 매일 중지되고, 유료로 가면 Railway와 비슷한 비용이다.
  - Oracle: 신규 가입 때 한국 리전을 고를 수 있는지 불확실하고, 유휴 회수 위험이 있다.
  - GCP: 카드가 필요하고, 외부 IP 과금 여부가 확인되지 않았다.
- 해외 IP 걱정: 주 소스(todaybeststory API)는 해외 IP에서도 동작하는 걸 확인했다. 영향은 예비 경로(직접 스크래핑)에만 있다.

### 구현
- `build.py`: 상태 복원 → 간격 가드 → 크롤 → 데일리 → 정적 렌더링. Flask 서버(`app.py`)는 삭제했다.
- `.github/workflows/pages.yml`: cron-job.org가 10분마다 `workflow_dispatch`로 부르고, `schedule`은 백업이다. 상태는 `actions/cache`로 이어받고, 권한은 잡별 최소로 줬다.
- 크롤러:
  - todaybeststory를 전량 수집한다. 결과는 약 460건, 21개 커뮤니티다(이전 172건, 13개).
  - `post.date`를 KST 계약 형식으로 통일하고, stale 처리를 넣었다.
  - 직접 스크래핑은 행 단위 파싱으로 다시 썼고, 인스타그램 코드는 제거했다.
- 데일리:
  - 저장소를 SQLite에서 `data/daily/*.json`으로 바꿨다.
  - 선정은 `rank_score` 기준에 소스당 최대 4개로 했다.
  - 12시 이후 정오본을 만들고, 다음 날 00:10~01:59에 최종본으로 덮어쓴다.
  - 입력 사실만 쓰는 프롬프트로 바꿨다. 첫 생성에서 정당 소속이 뒤바뀐 오류가 실제로 나서다.
- Gemini: 기본 `gemini-3.8-flash`. 3.x는 `thinkingLevel`을 쓴다. 5xx 백오프를 넣었다.
- 프론트: `{{ base }}` 서브경로, `data/trends.json` 로드, XSS 방어(escHtml·safeUrl), 요청 20초 타임아웃.
- 공개 전환 준비: 잡파일 15개를 추적에서 뺐고, 커밋 작성자 이메일을 GitHub noreply 주소로 다시 썼다.

### 배포 중 겪은 문제
- 새 Gemini 키(`AQ.` 형식)를 처음 붙여넣을 때 다른 문자열이 섞여 인증에 실패했다. 다시 복사해서 해결했다.
- cron-job.org → GitHub API 호출 문제:
  - `User-Agent` 헤더가 없으면 403이 난다.
  - fine-grained 토큰의 기본 접근 범위(Public repositories)로는 실행 권한이 없다. "Only select repositories"를 고르고 Actions에 Read and write를 줘야 한다.
  - TEST RUN만 누르면 작업이 저장되지 않는다. CREATE를 눌러야 한다.
- 9/24 00:26에 9/23 최종본 생성이 실패했다.
  - 원인: 3.8 Flash가 503을 연달아 내다가 일일 무료 한도까지 소진됐다. 재시도에 시간을 다 써서 예비 모델을 시도하지 못했다.
  - 조치: 예비 모델을 3.6 → 3.5 → 3.5-lite 체인으로 바꾸고, 기본 모델의 재시도는 예산 절반 안에서만 하게 했다.
- 단어 구름에 "있다", "들통난" 같은 서술어가 올라와서 불용어에 추가했다.
- 파비콘 세트를 추가했다: ico 16/32/48, apple-touch-icon, 매니페스트 아이콘.

### 운영 메모
- 사이트: https://gumoyaz.github.io/korean-community-crawler/
- 서치 콘솔: 새 속성 인증을 마쳤고(`GSC_VERIFICATION` 변수), `sitemap.xml`을 제출했다.
- Gemini 무료 한도는 모델마다 따로 있고, 태평양 자정(KST 16~17시)에 리셋된다.
- cron-job.org 토큰에 만료일을 걸었다면, 만료 전에 GitHub에서 재발급해서 교체해야 한다. 그러지 않으면 15분 백업 스케줄만 남는다.
- 수동 실행: Actions → Build and deploy → Run workflow. "간격 가드 무시"를 체크하면 바로 크롤한다.

### 알려진 한계
- 해외(Azure) IP에서 직접 스크래핑이 되는지는 확인하지 못했다. 주 경로인 API는 정상이다.
- TBS가 부분적으로 실패하고 예비 경로까지 전부 실패하면, 커뮤니티 수가 적은 목록이 `ok`로 통과할 수 있다.
- "승무원이"처럼 조사 '이/가'가 붙은 형태는 키워드에 남는다. "불꽃놀이"처럼 원래 '이'로 끝나는 명사가 잘리지 않게 하려고 일부러 남겼다.
- Actions `schedule`은 지연·누락이 잦아서 cron-job.org가 주 트리거다.
