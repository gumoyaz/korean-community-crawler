# 한국 SNS 트렌드 포착기

한국 주요 인터넷 커뮤니티를 크롤링해 **지금 막 급상승 중인 트렌드**를 감지하는 Flask 웹 앱입니다.

## 크롤링 소스

| 사이트 | 대상 | 조회수 |
|---|---|---|
| FMKorea 베스트 | 베스트 게시판 | 없음 (위치 점수만) |
| 오늘의유머 베스트 | bestofbest | O |
| 루리웹 베스트 | 커뮤니티 베스트 | O |
| 클리앙 인기 | 인기 게시판 | O |
| 더쿠 핫 | HOT 게시판 | 없음 |
| MLB파크 | 불펜 게시판 | 없음 |
| 인스타그램 | 해시태그 (접근 차단 시 샘플) | - |

각 사이트당 2페이지, 크롤링당 총 180~200개 포스트 수집

## 설치 & 실행

```bash
cd trend-crawler
pip install -r requirements.txt
python app.py
```

브라우저에서 http://localhost:5000

## 랭킹 로직

### 포스트 랭킹

두 점수를 합산해 전체 통합 순위를 매깁니다.

```
rank_score = 위치점수 × 0.4 + 조회수점수 × 0.6
```

**위치 점수** (0~100)
- 각 커뮤니티 목록에서의 순서 기반
- 1위 = 100점, 한 칸 내려갈 때마다 −3점
- FMKorea·더쿠·MLB파크처럼 조회수를 못 가져오는 사이트는 위치 점수만 사용

**조회수 점수** (0~60)
- 사이트마다 단위가 다르기 때문에 로그 정규화 적용
- `log(조회수+1) / log(최대조회수+1) × 60`
- 루리웹 100만 vs 오늘의유머 5천처럼 스케일이 달라도 공정하게 비교

### 키워드 트렌드 점수

```
trend_score = 현재빈도 기반 base + velocity_bonus × 3
velocity    = (현재 − 직전) × 2 + (현재 − 4회전 전)
```

- 과거 6회 크롤링 히스토리 유지
- `velocity > 0` 이고 `count >= 2`인 단어만 "급상승" 목록 노출
- 2회 이상 크롤링 후부터 급상승 데이터 활성화

### 키워드 필터링

단어 구름에서 의미 없는 단어를 제거하는 3단계 필터:

1. **길이 제한** — 6음절 이상은 동사구로 판단해 제외 ("핫하더라구요" 등)
2. **어미 제거** — 정규식으로 조사·어미를 제거 후 어근만 추출 ("닌텐도에서" → "닌텐도")
3. **STOP_WORDS** — 부사·접속사·지시어·SNS 상투어·일반명사 등 200개 이상 등록

## 포스트 요약

크롤링 완료 후 상위 25개 포스트에 대해 ThreadPoolExecutor(8 workers)로 병렬 접속해 본문 첫 문단을 130자로 잘라 요약으로 표시합니다. FMKorea는 접근 차단(430)으로 제외.

## 자동 갱신

- 서버 시작 시 즉시 첫 크롤링 (백그라운드 스레드)
- 이후 5분마다 자동 재크롤링
- 화면 하단 타이머 바로 다음 갱신까지 남은 시간 표시

## API 엔드포인트

| 엔드포인트 | 설명 |
|---|---|
| `GET /api/trends` | 전체 포스트 + 트렌드 데이터 |
| `GET /api/trends?source=ruliweb` | 특정 소스만 필터 |
| `GET /api/trends?tab=food` | 음식/카페 카테고리 |
| `GET /api/trends?tab=beauty` | 뷰티/패션 카테고리 |
| `POST /api/refresh` | 즉시 크롤링 시작 |
| `GET /api/status` | 크롤링 상태 확인 |
