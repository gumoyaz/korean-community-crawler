# 커트 — 커뮤니티 트렌드

한국 주요 인터넷 커뮤니티를 실시간 크롤링해 **지금 급상승 중인 트렌드**를 감지하는 Flask 웹 앱입니다.

## 크롤링 소스

| 사이트 | 대상 | 조회수 |
|---|---|---|
| FMKorea 베스트 | 베스트 게시판 | 없음 (Railway IP 차단으로 간헐적) |
| 오늘의유머 베스트 | bestofbest | O |
| 루리웹 베스트 | 커뮤니티 베스트 | O |
| 클리앙 인기 | 인기 게시판 | O |
| 더쿠 핫 | HOT 게시판 | 없음 |
| MLB파크 | 불펜 게시판 | 없음 (간헐적) |
| 인스티즈 | 실시간 베스트 | 없음 |
| 보배드림 | 자유게시판 | 없음 |
| 미즈넷 | 자유게시판 | 없음 |
| 웃긴대학 | 당일 인기 게시판 | 없음 |
| 인스타그램 | 해시태그 (차단 시 샘플) | - |

각 사이트당 1~2페이지, 크롤링당 총 180~220개 포스트 수집.

## 설치 & 실행

```bash
cd trend-crawler
pip install -r requirements.txt
python app.py
```

브라우저에서 http://localhost:5000

## 화면 구성

- **급상승 티커** — 상단 스크롤 배너, 실시간 급상승 키워드 표시
- **급상승 키워드** — velocity 기반 상위 10개 단어 + 상승폭
- **인기 단어 구름** — 클릭하면 해당 키워드 포함 글만 필터링
- **카테고리 탭** — 전체 / 게임·IT / 연예·아이돌 / 유머 / 음식·카페 / 뷰티·패션 / 자동차
- **커뮤니티 칩** — 가로 스크롤 + 화살표 버튼으로 사이트별 필터
- **카드 피드** — 이모지·소스 배지·요약·날짜 표시, 클릭하면 원글로 이동

## 랭킹 로직

### 포스트 랭킹

조회수 제공 여부에 따라 공식이 달라지지만, 두 경우 모두 최대 100점으로 동일하게 맞춰져 있습니다.

```
# 조회수 있는 사이트 (루리웹, 클리앙, 오늘의유머)
rank_score = (위치점수 × 0.5 + 조회수점수 × 0.5) × 시간감쇠   → 최대 100점

# 조회수 없는 사이트 (더쿠, 인스티즈, 웃긴대학 등)
rank_score = 위치점수 × 시간감쇠                               → 최대 100점
```

**위치 점수** (0~100)
- 각 커뮤니티 목록에서의 게시 순서 기반
- 1위 = 100점, 한 칸 내려갈 때마다 −3점

**조회수 점수** (0~100)
- 사이트마다 스케일이 다르므로 로그 정규화 적용
- `log(조회수+1) / log(최대조회수+1) × 100`
- 전체 수집 포스트 중 최대 조회수 기준으로 정규화

**시간 감쇠** (0.0~1.0)
- 지수 감쇠: `decay = e^(-나이(일) / 30)`
- 3개월(90일) 초과 글은 완전히 제외
- 날짜 정보가 없는 글은 감쇠 없이 유지

| 글 나이 | 점수 비율 |
|---------|---------|
| 오늘 | 100% |
| 1주일 전 | 79% |
| 1달 전 | 50% |
| 2달 전 | 25% |
| 3달 전 | 12% |
| 3달 초과 | 제외 |

### 키워드 트렌드 점수

```
trend_score = 현재빈도 기반 base + velocity_bonus × 3
velocity    = (현재 − 직전) × 2 + (현재 − 4회전 전)
```

- 과거 6회 크롤링 히스토리 유지
- `velocity > 0` 이고 `count >= 2`인 단어만 "급상승" 목록 노출
- 2회 이상 크롤링 후부터 급상승 데이터 활성화

### 키워드 필터링

단어 구름에서 의미 없는 단어를 제거하는 3단계 필터:

1. **길이 제한** — 6음절 이상은 동사구로 판단해 제외
2. **어미 제거** — 정규식으로 조사·어미를 제거 후 어근만 추출 ("닌텐도에서" → "닌텐도")
3. **STOP_WORDS** — 부사·접속사·지시어·SNS 상투어·일반명사 등 200개 이상 등록

## 포스트 요약

크롤링 후 상위 25개 포스트에 대해 `ThreadPoolExecutor(8 workers)`로 병렬 접속해 본문 첫 문단을 130자로 잘라 표시합니다. FMKorea는 접근 차단(430)으로 제외.

## 자동 갱신

- 서버 시작 시 즉시 첫 크롤링 (백그라운드 스레드)
- 이후 5분마다 자동 재크롤링
- 화면 하단 타이머 바로 다음 갱신까지 남은 시간 표시

## API 엔드포인트

| 엔드포인트 | 설명 |
|---|---|
| `GET /api/trends` | 전체 포스트 + 트렌드 데이터 |
| `GET /api/trends?source=ruliweb` | 특정 소스만 필터 |
| `GET /api/trends?tab=food` | 음식/카페 카테고리 |
| `GET /api/trends?tab=beauty` | 뷰티/패션 카테고리 |
| `GET /api/trends?tab=game` | 게임/IT 카테고리 |
| `GET /api/trends?tab=celeb` | 연예/아이돌 카테고리 |
| `GET /api/trends?tab=humor` | 유머 카테고리 |
| `GET /api/trends?tab=car` | 자동차 카테고리 |
| `POST /api/refresh` | 즉시 크롤링 시작 |
| `GET /api/status` | 크롤링 상태 확인 |
